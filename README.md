Sprite Shuffler

If you ask ChatGPT to generate a tilesheet for you it tends to put the different
tiles and sprites just wherever, not on any sort of useful grid boundaries.  This app
lets you quickly select and move things around within an image; shows you where the
sprite boundaries are; and lets you enlarge the image if they don't quite fit.  You could
do all this with Gimp or Photoshop, this just speeds up the workflow.

Click and drag to select a sprite, then move it to where you want it to be, then click
to drop.

This was vibe-coded with ChatGPT-5.

If you are using ChatGPT-generated tilesheets you may have noticed its pixel art isn't
actually real pixel art.  I made an app to turn it into real pixel art, which is freely
available at https://jpmodisette.github.io/pixelfixer
